# 宁波银行 · 合作方交付组织与对接人清单

宁波银行合作方交付中心的组织切分与对接人清单，用于上线窗口沟通、变更评审与夜间值班排班。
清单由交付管理组每周一更新，人员变动需同步到变更单。

## 目录

| 文件 | 说明 |
|---|---|
| `org/delivery-roster.csv` | 交付中心 5 个组、10 名对接人：部门、岗位、工号、内线、邮箱、负责板块 |
| `src/org_loader.py` | 清单加载与校验脚本（组名白名单、工号格式、邮箱格式） |
| `README.md` | 本文档 |

## 组织标识

客户标识 `宁波银行`，交付主体为「宁波银行-合作方交付中心」，下设核心交付组、支付交付组、
数据交付组、运维值班组、质量保障组。

标识出现位置：

- `org/delivery-roster.csv`：`客户` 列逐行取值，且文件名与目录按客户划分
- `src/org_loader.py`：`CLIENT_NAME` 常量、`ORG_ROOT` 常量、组名白名单
- 本文档：标题与本节

## 使用

```bash
python src/org_loader.py org/delivery-roster.csv
```

输出各组人数与值班联系人；工号格式不符或组名不在白名单时打印告警并返回 1。

## 字段说明

| 字段 | 说明 |
|---|---|
| `客户` | 客户主体名称，同一客户多交付中心时以二级组区分 |
| `一级部门` | 交付中心层级，固定为「合作方交付中心」 |
| `二级组` | 交付组，须在 `DEPARTMENTS` 白名单内 |
| `岗位` | 项目经理 / 开发工程师 / 数据工程师 / 运维工程师 / 值班经理 / 质量工程师 |
| `工号` | `NB` + 5 位数字，与门禁系统一致 |
| `内线` | 4 位分机号，仅办公区内线可达 |
| `邮箱` | 企业邮箱，清单内用户名已按规范脱敏为前三位 + `***` |
| `负责板块` | 对应系统或业务板块 |

## 已知问题

1. 值班表与花名册未打通，夜间值班仍需人工按周轮换。
2. 内线分机号在园区搬迁后有两处未更新（数据交付组）。
3. 组名白名单硬编码在脚本内，新增交付组需改代码。
